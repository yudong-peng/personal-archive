# 个人档案库 v0.3.0

本版新增证件／证书到期提醒、AI 辅助录入与桌面悬浮窗。档案管理仍可离线使用，AI 默认关闭。

## 新增功能

- 有效期提醒：支持身份证、学生证、其他证件和证书资质；设置提醒天数、单项关闭及稍后提醒。
- 半透明悬浮窗：快速创建标题与附件记录，或为已有资料追加附件；支持拖拽、置顶、折叠和下载记录。
- 收集箱：暂存待整理材料，可重新分类或将附件复制到已有资料，重复原件自动跳过。
- AI 辅助录入：使用自己的兼容 API，识别图片或指定 PDF 页面；逐项核对后填写，支持撤销和证件附件关联。

## 保留功能

密码与 Windows Hello、资料与下载目录选择、分类表单、全页个人／家庭信息、附件命名与本地预览、主题切换、分栏拖动、材料导出和加密备份。

## 下载与更新

首次使用请下载完整 Windows x64 程序包，完整解压后启动 PersonalArchive.exe。

已有使用者可使用适用 v0.2.0～v0.2.3 原始发布构建的更新包：完全退出程序，解压更新 ZIP，运行 apply-update.bat 并选择原程序目录。更新程序校验原资源哈希；首次解锁会保留升级前加密档案备份。

## 使用说明与验证范围

AI 需要自行配置 API Key、地址和支持所需输入类型的模型；只在明确发送后调用，费用由用户 API 账户承担。普通导出不带档案密码保护。

有效期检查在档案已解锁且程序运行时进行；完全退出后不提醒。自动锁定会清空未保存的编辑和悬浮窗内容。

当前自动化覆盖 64 项单元测试与 99 项 Electron 桌面检查。Windows Hello 使用模拟接口回归，AI 使用本机模拟接口；真实 Windows 更新脚本、系统通知、开机启动、生物识别硬件和收费 API 的实测情况请在发布时如实填写，不应将模拟检查写成实机通过。
