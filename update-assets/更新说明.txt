个人档案库 v0.3.0 增量更新（Windows x64）
适用：此前提供的 v0.2.0、v0.2.1、v0.2.2、v0.2.3 网页界面桌面版。

安装
1. 完全退出个人档案库，包括托盘中的程序。
2. 将整个 ZIP 解压到临时文件夹，不要在 ZIP 内直接运行。
3. 双击 apply-update.bat，选择原来包含 PersonalArchive.exe 的程序文件夹。
4. 更新完成后，仍从原目录的 PersonalArchive.exe 启动。
更新程序校验原程序资源和补丁哈希，原程序资源备份到 .update-backups。
更新程序不移动资料、不更改密码或 Windows Hello 凭据。
首次解锁时会在当前资料目录的 backups 中另存 before-v0.3.0 加密备份。

本版新增
一、证件与证书到期提醒
- 首页“有效期提醒”集中查看需提醒、全部和有效期待补充的条目。
- 支持身份证、学生证、其他证件及证书资质。
- 证书资质新增明确的“有效期截止”，旧“有效期”文字保留。
- 截止当天显示今天到期；下一天显示已过期。
- 只有年份或年月时，分别按该年末或月末计算；长期有效不提醒。
- 默认应用内提醒开启、提前30天；每份证件可单独关闭、调整天数或稍后7天提醒。
- Windows 系统通知单独开启，只显示数量。仅在档案已解锁且程序运行时检查；锁定后暂停，解锁后重新检查，完全退出后不提醒。

二、收集箱和桌面悬浮窗
- 从首页“悬浮窗”开启，或在设置中开启。支持标题、拖入附件和点击选择文件。
- 新记录进入收集箱；也可搜索已有资料并添加附件。
- 支持置顶、移动、折叠及60～100%背景不透明度，文字保持清晰。
- 选择的附件先暂存，点击保存后才写入加密档案。
- 已保存的待整理记录不会自动删除；未保存内容在自动锁定时清空。
- 收集箱支持编辑后重新分类，以及将附件复制到已有资料，重复文件自动跳过，来源保留。
- 悬浮窗可导出整条记录和附件ZIP、TXT、JSON，使用默认下载目录或另选目录。
- 与主程序共享登录、锁定、数据目录和下载目录。
- 可选关闭主窗口后驻留托盘，以及Windows开机启动；默认均关闭。

三、可选 AI 辅助录入
- 设置与备份 → 提醒、悬浮窗与AI：配置总开关、API Base URL、API Key、模型名称。
- 第一版适配OpenAI兼容的Chat Completions文字／图片协议；提供OpenAI、百炼、DeepSeek及本机接口预设。
- 预设地址可以修改。各服务的模型、地域和兼容接口能力不同，需选择实际支持的模型。
- 不包含Claude、Gemini原生协议适配；它们需要兼容接口才可在本版使用。
- 图片需要视觉模型。PDF在本地选择页码后，转为页面图像或提取文字，后者可用文字模型。
- PDF密码只用于本地打开，不会发送到API；原始PDF无需上传到公开网址。
- 点击“发送所选材料并识别”才发送所选材料、来源附件标识及目标字段名称。
- 不发送其他记录、整个数据库或现有字段值；原始文件仍加密保存在本地。
- 候选结果显示现有内容、建议值、来源文件和页码；模糊结果及已有值默认不选中。
- 用户选择字段并确认后才写入，可撤销上次AI填写；再次手工修改字段后，不直接撤销以免覆盖人工内容。
- 识别证件时可创建或填写个人基本信息中的证件组；普通资料按目标分类辅助填写。
- 收集箱识别后可转为普通分类；已有个人／家庭信息时，请先将附件复制至已有资料再识别。
- 悬浮窗有本次AI开关，受全局开关控制；保存后进入同样的材料选择和核对流程。
- API Key使用本机系统加密，不进入普通导出、加密档案或其备份。换设备需要重新填写。
- 若系统安全密钥存储不可用，仅在本次解锁会话中保留Key，锁定后清除。
- 支持测试连接、合成测试图片、取消、超时和页数上限；调用费用由用户API账户承担。
- 未配置或关闭AI时，其他功能均可离线使用。

保留原有功能
密码和Windows Hello登录、资料与下载目录选择、分类表单、全页个人／家庭信息、证件分组、附件命名与预览、拖拽上传、主题切换、分栏拖拽、导出与备份均保留。

手动更新（仅在无法运行更新脚本时）
先完全退出，备份原目录中的 resources/app.asar、对应的 app.asar.unpacked 和 version.txt。
将更新包中的 resources 文件夹及 version.txt 复制到原程序目录，合并并覆盖同名文件。
不要删除原程序的其他文件，不要覆盖或删除自己的资料目录。

回退
原程序资源保存在原程序目录 .update-backups/before-0.3.0-*。
如需完整退回升级前的数据状态，应配合首次解锁生成的 before-v0.3.0-*.pav 加密备份；恢复会替换当前档案，请先另存新资料。
更新不会自动上传资料，也不会自动启用AI、系统通知、悬浮窗、托盘驻留或开机启动。
