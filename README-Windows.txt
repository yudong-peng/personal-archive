个人档案库 v0.3.0 · Windows x64

完整解压程序文件夹，双击 PersonalArchive.exe 启动。
请保留同目录的 resources、locales、DLL 等文件，不要只复制 EXE。
首次创建密码并保存恢复密钥；资料位置可以在程序中自行选择。
日常管理可离线使用；AI 默认关闭，只有配置自己的 API 并点击识别时才联网。

本版包含有效期提醒、AI辅助录入与核对撤销、半透明悬浮窗及收集箱。
系统通知、悬浮窗、托盘驻留与开机启动均需要自行开启。
到期提醒在程序运行且资料已解锁时检查，完全退出后不会提醒。
未保存内容会在自动锁定时清空；已保存的收集箱记录不会自动删除。

普通导出文件不带档案密码保护。请勿将个人档案、恢复密钥、API Key或设备凭据上传到GitHub。
更多说明见源码仓库 README.md 和 docs 目录。
